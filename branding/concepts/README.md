# Realms GOS logo concepts

## Chosen: 04 Clover (quatrefoil Venn) — official Realms GOS mark

**Concept 04 (clover)** is the chosen Realms GOS logo. Use these files (or their deployed copies) for all Realms GOS product surfaces.

Four overlapping cardinal circles — solid fill with contrasting strokes so every intersection arc stays visible.

| File | Use |
|------|-----|
| `04-clover-mark.svg` | Icon / favicon (black) |
| `04-clover-mark-white.svg` | Icon on dark backgrounds |
| `04-clover-horizontal.svg` | Nav / wordmark (black) |
| `04-clover-horizontal-white.svg` | Wordmark on dark backgrounds |

Deployed into `src/*/static/images/`, `website/public/`, `docs/`, and CLI mirrors as `logo_mark.svg`, `logo_horizontal.svg`, etc. Legacy filename `logo_sphere_only.svg` now contains this clover (kept for path compatibility).

## Reserved for GaaS / gos.earth only

The **dotted sphere** (historically `logo_sphere_only`) is **not** the Realms GOS mark. Reserve it for **GaaS / gos.earth** branding only. In Realms GOS deployments, `logo_sphere_only.svg` paths now serve the clover mark for backward compatibility.
