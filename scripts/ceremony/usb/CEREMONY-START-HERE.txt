Realms YubiKey key ceremony — Ubuntu 22.04 Desktop live USB
=============================================================

Boot this USB → choose "Try Ubuntu" (do NOT install to disk).

1. Double-click **Realms Key Ceremony** on the desktop.
   A terminal opens in /opt/realms-ceremony (scripts attach automatically).

2. Packages (ykman, ykcs11, dfx, …) may need online-setup on first boot:

   sudo ./realms-key-ceremony.sh online-setup

3. BEFORE offline-generate — choose operator PIV credentials (optional)
   ---------------------------------------------------------------------
   By default the ceremony generates random PIN / PUK / management key.
   To use your own, create a private file BEFORE offline-generate:

     cp operator-credentials.example /tmp/my-piv.txt
     chmod 600 /tmp/my-piv.txt
     nano /tmp/my-piv.txt

   Edit PIV_PIN and PIV_PUK (each 6–8 characters). PIV_MANAGEMENT_KEY is
   optional (48 hex chars); omit it to get a random management key.

   Then pass it to offline-generate (not to provision-prod):

     sudo ./realms-key-ceremony.sh offline-generate --credentials-file /tmp/my-piv.txt

   Record the values on paper at finalize. Shred /tmp/my-piv.txt during destroy.
   Do NOT commit real credentials to git.

4. YubiKey hardware prep
   ----------------------
   • Use factory-fresh keys, OR keys you are willing to wipe for ceremony.
   • QEMU / VM: plug the YubiKey into the host BEFORE starting the VM.
     On the host: sudo systemctl stop pcscd
     Restart the VM if you forgot — USB passthrough is only set at boot.
   • If a key already has a custom PIV PIN (not factory 123456), provision
     must reset PIV first (wipes PIV slots/PIN/PUK/mgmt — FIDO/OTP unchanged).
     piv reset does NOT ask for the old PIN.

     CEREMONY_PIV_RESET=1 sudo -E ./realms-key-ceremony.sh provision-prod

   • To migrate an existing PIN instead of reset, set CEREMONY_CURRENT_PIV_PIN
     (and CEREMONY_CURRENT_PIV_MANAGEMENT_KEY if not factory) — see README.md.

5. Disconnect ALL network (Wi‑Fi off, Ethernet unplugged).

6. OFFLINE ceremony:

   sudo ./realms-key-ceremony.sh check-offline

   # random PINs:
   sudo ./realms-key-ceremony.sh offline-generate

   # OR your PINs (step 3):
   # sudo ./realms-key-ceremony.sh offline-generate --credentials-file /tmp/my-piv.txt

   sudo ./realms-key-ceremony.sh provision-dev      # insert dev YubiKey 5C Nano
   CEREMONY_PIV_RESET=1 sudo -E ./realms-key-ceremony.sh provision-prod   # 3× NFC
   sudo ./realms-key-ceremony.sh finalize

   Or all-in-one (random PINs only): sudo ./realms-key-ceremony.sh run-offline

7. finalize writes the verification bundle automatically (public material
   only): this USB's "CEREMONY DATA" volume, or the host share in a test VM.
   Write PIN / PUK / management key from secrets/operator-credentials.txt
   on paper — they are not in the bundle.

8. On a trusted laptop, mount CEREMONY DATA and run:

   ./verify-yubikeys.sh --manifest manifest.json --env prod
   ./verify-yubikeys.sh --manifest manifest.json --env dev

9. Wipe ceremony workspace and power off:

   sudo ./realms-key-ceremony.sh destroy
   sudo poweroff

Hardware: dev = YubiKey 5C Nano (touch never); prod = 3× YubiKey 5 NFC (touch cached).

Full docs: README.md and operator-credentials.example in this directory.
